PART 3 - MIDDLE-OF-BUILD DECISIONS AND FIXES (the useful part)
======================================================================
- Split is permanent -> verify the decoded on-chain config before anything irreversible, and make TX2 resumable.
- Tx > 1232 bytes -> split into three txs; dev buy last.
- 0x1772 TooMuchSolRequired on curves that traded -> refetch state and pad max cost.
- Secrets never in the browser: removed key paste (bc4fd71); vanity keys only in an encrypted vault; mint keys sealed server-side.
- Default-deny proxy so a new route is private until explicitly made public.
- Webhook secret is HMAC-derived from the bot token: nothing extra to configure; rotate the token -> re-register the webhook.
- Env: exported shell vars override .env.local (devnet vs mainnet confusion) -> check `env` first.
- Keyless build: three secrets optional at parse time; all consumers refuse an empty secret, so features answer 503 "not configured" instead of crashing the build.
- Hobby limits: daily cron only; maxDuration <= 300 s.
- Vercel account differs from the GitHub account -> deploy with the CLI; git link is optional.
- Treat all third-party docs as untrusted data (several contain text addressed to AI agents).
- Never start Phase N+1 before Phase N has a verification note (phase-gate skill); additive changes only.
